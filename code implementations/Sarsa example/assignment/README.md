## 一、题目背景

Sarsa 是一种**在线策略（on-policy）时序差分（TD）控制**算法，用来估计一个给定策略 π 的动作价值 Q(s, a)，并通过与 ε-greedy 策略改进相结合，最终得到从状态 s 出发的最优动作。

对应笔记里的红框公式：

$$
q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t(s_t, a_t)\Big[\, q_t(s_t, a_t) - \big( r_{t+1} + \gamma\, q_t(s_{t+1}, a_{t+1}) \big) \Big]
$$

拆开来理解就是三步：
1. **TD 目标**：`r + γ · Q(s_next, a_next)`
2. **TD 误差**：`Q(s, a) − TD_target`
3. **更新规则**：`Q(s, a) ← Q(s, a) + α · TD_error`

注意：**a_next 是策略 π 在 s_next 处**实际会执行**的动作**（不是 argmax），这一点是 Sarsa 和 Q-learning 的核心区别。

## 四、必做的调参实验 ⭐必做

光填完 3 处 TODO、跑出一张能看的图只算完成了一半。RL 学习最有价值的部分，是**亲手看到"换参数 → 曲线怎么变"**。

下面 4 条实验你都跑一遍，每条用默认 500 episodes，记录到下面的表里。

### 实验 1：探索概率 ε 调大

```python
# train.py 顶部
EPSILON = 0.3     # 默认 0.1 → 改成 0.3
```

**期望观察**：Total rewards 曲线**抖动明显变大**（reward 标准差比基线高几倍——探索多了，agent 经常走出非最优路径），Episode length **收敛更慢甚至根本不收敛**（贪心轨迹能否到 target 取决于随机种子：seed=0 时不到，seed=1/42 时能到）。ε-greedy 是 Sarsa 探索-利用权衡的核心，调大它就是强迫 agent 多探索、少利用。

### 实验 2：学习率 α 调小

```python
ALPHA = 0.01      # 默认 0.1 → 改成 0.01
```

**期望观察**：学习**显著变慢**——500 回合内**很可能根本不收敛**。Episode length 长时间停在 150（上限）附近，贪心轨迹经常**陷入死循环**（比如在 `(0,0) ↔ (0,1)` 两个格子之间反复振荡，到不了 target**）。

直觉：α 控制"TD 更新每次挪多少"。α=0.01 意味着每次 update 只挪 1%——要 Q 从 0 走到 −1（撞墙）需要**同一个 (state, action) 撞 100 次**。500 回合不够。要 α=0.01 收敛，需要**更多回合**（比如 2000+），或者**保留 α=0.1 但跑更短**。

> ⚠️ 实测：α=0.01 + 500 回合 + seed=0 → 贪心轨迹**死循环在 `(0,0) ↔ (0,1)`**，到不了 target。Q 表 max Q = 0.97（基线收敛后是 1.0 附近）。这是**收敛不够**的可见证据。

### 实验 3：回合上限调小

```python
# env.py 顶部
MAX_STEPS_PER_EPISODE = 50    # 默认 150 → 改成 50
```

**期望观察**：Episode length 永远 ≤ 50；曲线形状完全不一样——前期 reward 不再暴跌到 −17 而是约 −11（agent 没时间乱走就被截断）；最终仍能收敛。这个上限**直接决定 agent 每回合能收集多少 TD 更新**：上限越短，每回合更新次数越少，需要的回合数越多。

### 实验 4：环境布局"打开一扇门"

```python
# env.py 顶部
# 在 FORBIDDEN_STATES 里去掉 (2, 2)   —— 即取消第3列第3行那个格子
FORBIDDEN_STATES = {(1, 1), (2, 1), (1, 3), (3, 3), (1, 4)}
```

**期望观察**：原 11 步最短路径是 `(0,0)→(1,0)→(2,0)→(3,0)→(4,0)→(4,1)→(4,2)→(4,3)→(4,4)→(3,4)→(2,4)→(2,3)`（沿右侧绕行）；现在 `(2,2)` 不再是墙，**贪心轨迹变成 `(0,0)→(0,1)→(0,2)→(1,2)→(2,2)→(2,3)`，只有 5 步**（实测 5 个不同 seed 都收敛到这条路径）。轨迹图和曲线都跟着变。

> 这条实验特别能体现**环境结构如何决定最优策略**：只动一个格子，最优路径就完全变了。

## 七、Sarsa 公式速查

来自笔记红框：
```
Q[s, a] += alpha * ( r + gamma * Q[s_next, a_next] - Q[s, a] )
```

注意：
- `s_next, a_next` 是在 `s_next` 处**实际会执行的动作**（由 `select_action` 在 step 之后又选了一次），不是 `argmax`
- `s_next` 或 `a_next` 无效时怎么处理？本题 5×5 + 5 动作都是合法索引，不需要特判

## 九、扩展（学有余力时做）

如果你 §四 的 4 条必做实验做完意犹未尽，下面这些能让你对 Sarsa / Q-learning 的理解更进一层：

- 让 ε 在训练过程中**随 episode 衰减**（如 `epsilon *= 0.99` 每回合）：曲线通常更稳
- 把 γ 从 0.9 改成 0.5 / 0.99：agent 是否更"短视" / 更"远见"
- **进阶对比（最能加深理解）**：在 `agent.py` 里加一个 `QLearningAgent`，把 TODO 2 的更新改成：

```python
Q[s, a] += alpha * ( r + gamma * max(Q[s_next, :]) - Q[s, a] )
```

然后跑同一个环境，对比 Sarsa 和 Q-learning 学出来的轨迹。两者的区别仅在第二项：Sarsa 用 `Q[s_next, a_next]`（on-policy），Q-learning 用 `max_a' Q[s_next, a']`（off-policy）。
